02 / Installation

Build on the
right foundation.

  1. Use Minecraft Java EditionThese builds target Minecraft 1.21.11 with Forge 61 or later. They are not Bedrock add-ons or Fabric mods.
  2. Prepare your Forge profileInstall the matching Forge loader for Minecraft 1.21.11 and launch that profile once to create its folders.
  3. Add the JAR filesClose the game and place either or both downloaded JARs in that profile’s mods folder. Leave the JARs compressed.
  4. Launch with ForgeStart the same Forge profile and check the Mods list. For a modded server, use matching game, loader and mod versions on both sides.

Versions and requirements come from the metadata inside the published JARs. Back up an existing world before adding mods.
