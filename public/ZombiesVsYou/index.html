02 / Before launching

Keep the
build together.

  1. Download the whole archiveUse the archive above rather than downloading the EXE by itself.
  2. Extract every fileKeep ZOMBIES Vs. YOU.exe, ZOMBIES Vs. YOU_Data and the runtime folders together.
  3. Check the runtimeA complete build must include UnityPlayer.dll beside the EXE. The repository currently lacks it; do not download a random replacement DLL.
  4. Run a complete Windows buildOnce all companion files are present, open ZOMBIES Vs. YOU.exe on Windows. This is a downloadable prototype, not a browser game.
