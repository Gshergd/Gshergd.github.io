  1. Extract the downloadUnzip the package into a permanent folder. Keep that folder after installation.
  2. Open Chrome’s extension managerType chrome://extensions/ in the address bar and enable Developer mode.
  3. Load unpackedChoose Load unpacked and select the extracted folder containing manifest.json. Open a new tab.
